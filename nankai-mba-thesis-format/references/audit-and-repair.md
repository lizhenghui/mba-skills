# DOCX 审核与修复工作流

## 一、开始前

1. 复制原文件并在新文件上工作。
2. 读取完整文档结构：段落、样式、分节、页眉页脚、页码域、目录域、表格、图片、题注、脚注和参考文献。
3. 用 `scripts/audit_docx.py` 生成首轮结构报告。
4. 渲染当前版本并逐页观察；不能仅依靠 XML 或文本抽取判断分页。

## 二、修复顺序

按以下顺序处理，避免后续修改反复改变页码：

1. **结构**：封面、声明、摘要、目录、正文、参考文献、附录、致谢及分节位置。
2. **页面**：A4、页边距、页眉页脚距离、单双面和右页起章所需空白页。
3. **样式**：Normal、章、节、目、更深层级、目录、图题、表题、来源、参考文献、致谢。
4. **对象**：图、表、表达式、题注、来源、连续编号、跨页表头。
5. **引文**：正文著者—出版年制、文后条目方括号顺序编码及文末排序；核对编号从 1 起连续，并确保正文引文与文后条目一一对应。
6. **导航**：页眉、罗马/阿拉伯页码、目录域、图表清单和交叉引用。
7. **微调**：孤行、寡行、标题页末、章尾以外的大空白和分页稳定性。

## 三、实现原则

- 以 Word 命名样式承载格式，不对大量段落重复直接格式化。
- 标题使用语义样式和真实层级；MBA目录只收录章、节、目三级。
- 使用真实分节符控制前置部分和正文页码；不要用连续空行模拟分页。
- 页眉下划实线用页眉段落的段落下边框（`w:pBdr` 底边框）实现；不要用文本框、图片、连续下划线或空格底纹模拟。
- 目录优先使用 TOC 域。静态目录仅作为渲染兼容的最后手段，并必须由实际分页生成。
- 图题、表题和交叉引用优先使用 Caption/SEQ/REF 域；若目标软件不能稳定更新域，可物化显示文本，但保留可核对编号。
- 表格设置明确列宽、重复表头和三线边框；不要用文本框或截图代替可编辑表格。
- 不压缩正文到低于规定字号或行距来消除分页问题。

## 四、逐页视觉检查

最终版本逐页检查以下项目：

- 中文字形是否缺失，是否出现替代字体、乱码、方框或断字；
- 页边距、页眉、页码和装订侧是否一致，页眉文字下方是否有统一的下划实线；
- 标题未落在页末，标题后至少有正文；章是否另起页；
- 除章尾外是否出现非必要的大块空白；
- 图在相关文字之后，题注在图下、来源齐全、打印清晰、无水印；
- 表在相关文字之后，题注在表上、三线表完整，跨页时重复表头并有续表标识；
- 公式未截断，编号右对齐；
- 目录层级、点引导符和页码与正文一致；
- 参考文献没有孤立条目、异常换行或中外文混排顺序错误。

如果 LibreOffice 渲染中文缺字而 Word/Pages 正常，使用 Word 或 Pages 的 PDF 导出作为视觉判定依据，并记录所用渲染器。

- **页码显示异常**：如果目录正文首显示了 Ⅴ 而前一个罗马页是 Ⅲ，通常是该节的分节起始方式被设成了“奇数页”，LibreOffice 会吃掉一个罗马页码而不产生空白页；把该节改为“下一页”即可（前提是该页本身落在奇数物理页上）。定位节时优先用 `doc.sections` 按页眉内容匹配，不要自己顺序倒查 sectPr——sectPr 挂在“上一个节的最后段落”上，容易找错。

### 检查 run 级覆写，不要只看样式

样式对不代表渲染对。以下两处高频出问题：

- 关键词行常被整行设为黑体加粗，规范只要求“关键词”三个字加粗，其余同摘要正文（宋体 12 磅）；英文行曾被整行设为 `Times New Roman Bold` 这种假粗体，应改为 Times New Roman 12 磅且只有 `Key Words` 加粗。
- 致谢常被段落级 `w:spacing`（20 磅）和 run 级 `w:rFonts`（宋体）双重覆写，导致样式里的仿宋 12 磅、固定值 16 磅完全失效。

核对时要读 `w:rPr/w:rFonts`、`w:b` 和段落 `w:pPr/w:spacing`，确认为空才是继承；修改时应删除覆写而不是简单地再写一层。

肉眼翻页容易漏项，建议渲染后用脚本量化以下四项，把“逐页检查”变成可复核的数据：

- **目录页码核对**：从 DOCX 读 toc 条目，提取 PDF 每页文本并去掉空白与引号差异后匹配标题所在物理页。注意：**静态目录本身会把所有标题串在同一页上**，检索正文时必须跳过目录页（同一页命中标题数≥8 即判定为目录页），否则全部条目都会误判为“页码不符”。
- **底部留白**：pypdfium2 用 `page.get_objects()` + `obj.get_bounds()` 取内容最低横坐标，换算成厘米；`get_pos()` 在部分版本不可用。封面、声明、审批表等前置页留白大是正常的，只对正文判定。
- **每节篇幅**：按 Heading 2 起止物理页相减，小于 1 页即违反“MBA 每节篇幅长于一页”。
- **插图清晰度**：用 FPDF_PAGEOBJ_IMAGE 统计每页图像并还原其厘米尺寸，确认未被裁切（插图段落若继承固定行距会被裁掉下半部分，必须显式单倍行距）。

## 五、最终结构检查

- 重新运行 `scripts/audit_docx.py`。
- 运行 DOCX ZIP 完整性检查。
- 检查目录、页码、SEQ/REF/PAGEREF 域是否更新。
- 检查是否残留批注、修订、占位文本或个人元数据；只有用户要求清稿时才接受修订或清除批注。
- 输出“已修复、未改动、需作者确认”三类结论，不把建议项描述为强制不合格。
